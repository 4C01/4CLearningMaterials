# 涅科格勒道路铺设规范（送审稿）

本稿用于涅科格勒经济开发区的道路放样、铺设和验收，不适用于其他地区。下文长度均以游戏内方块（格）计。

## 一、放样：先量车道净宽

垂直于行车方向量取两条边线之间可行车的宽度，不把边线、停车位或安全空位计入净宽。相邻车道共用一条分隔线，计算整幅道路时只计一次。

| 路段 | 单车道净宽 | 连同两侧各1格标线 |
|---|---:|---:|
| 城市道路 | 3格 | 5格 |
| 高速公路一般路段 | 4格 | 6格 |
| 高速公路转弯带 | 5格 | 7格 |

城市道路在两侧边线外各预留约2格，作停车与安全空位。不要为了留停车位而挤占车道净宽。

**图1　城市双向双车道横断面（每字一格）**

```text
灰灰灯灰灰灰灯灰灰灰灯灰灰
 2  1   3   1   3   1  2    ← 各段格数
```

从左到右依次为：安全空位、边线、车道、中央分隔线、反向车道、边线、安全空位。灰为灰色混凝土，灯为海晶灯；图示铺法合计13格。

## 二、铺线：区分纵向线、方向箭头和停止线

**方向线与虚线。** 用海晶灯铺设指示道路走向的纵向线。图1中的两条外侧边线和一条中央分隔线均用海晶灯。其他需划线处用白色混凝土。划虚线时沿线反复铺设「2格灰色混凝土＋3格白色混凝土」；灰段是间隔，不是留空。

**方向箭头。** 沿行车方向连续铺4格白色混凝土作为箭杆。允许直行时，将允许的转向分支接在箭尖**后退1格**处，留下最前方1格表示直行；禁止直行时，把分支接在箭杆**最前端**，不再向前伸出。左右一律按驾驶者面向路口的方向判断。

**图2　箭头俯视图**（车辆从右向左行驶，图上方为驾驶者右侧；`1` 为白色混凝土，`0` 为保留路面）

```text
直行、左转、右转均可     仅右转
0100                    1000
1111                    1111
0100                    0000
```

**停止线。** 在信号灯前驶向路口的车道末端，用白色混凝土横向划停止线。停车以车轮不越过白线为准。不要把白线横贯对向车道：从路口驶入路段的一端无需“封口”。

**图3　双向道路在路口同一侧的画法**（示意，不按比例）

```text
路段内                      路口
驶向路口   → → → → →   │    （白色停止线）
驶入路段   ← ← ← ← ←        （入口留开）
```

## 三、限速

城市道路限速 **40**，高速公路限速 **100**，高速公路匝道限速 **60**。转弯带的5格是净宽要求，不是匝道宽度。速度单位尚未确认，本稿不自行换算或补写单位。

## 四、现场验收

| 检查项 | 现场核对方法与合格判据 |
|---|---|
| 车道尺寸 | 在直段横数两线之间的格数，按路段核对3格或4格；另查高速转弯带净宽为5格。不能用含线宽度代替净宽。 |
| 道路两侧 | 城市道路两侧线外各留约2格停车与安全空位。按图1施工时，横数应为13格，中央只设一条共用分隔线。 |
| 材料与节奏 | 对照图1查海晶灯线位；在有虚线处沿线数一个完整重复段，应为2灰、3白。 |
| 行驶方向 | 从驾驶者方向读箭头，与该车道允许的去向逐一比对。重点查允许直行与仅转弯两种箭头的分支是否错开1格。 |
| 停车位置 | 面向信号灯查本车道末端有横向白线，反向入口未被该线封口。 |
| 限速数值 | 分别对照城市道路、高速公路及匝道的限速数值，勿把高速主路的100延用到匝道。 |
